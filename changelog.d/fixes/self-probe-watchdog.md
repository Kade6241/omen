- **fix(resilience):** `server-ws.mjs` now installs a loopback self-probe watchdog that exits the process if `/api/status` stops answering — the September 2026 opencode h2-stream-reset wedge left the listener accepting but no request served; the existing supervisor only restarted on process exit. Configurable via `OMNIROUTE_SELF_PROBE=off` to disable, plus `OMNIROUTE_SELF_PROBE_INTERVAL_MS` (default 60000), `OMNIROUTE_SELF_PROBE_TIMEOUT_MS` (default 15000), `OMNIROUTE_SELF_PROBE_THRESHOLD` (default 3). Pack-artifact closure tests (`pack-artifact-server-ws-closure`, `pack-artifact-entrypoint-closures`, `build/assemble-standalone`) updated to register the new module.
